# Contact Management System

## Project Description

A Python-based Contact Management System that demonstrates Functions, Dictionaries, File Handling, JSON Storage, Validation, and CRUD Operations.

## Features

* Add Contact
* Search Contact
* Update Contact
* Delete Contact
* View Contacts
* Export CSV
* Statistics Dashboard
* JSON Data Storage
* Email Validation
* Phone Validation

## Run Project

```bash
python contacts_manager.py
```

## Run Tests

```bash
python test_contacts.py
```
